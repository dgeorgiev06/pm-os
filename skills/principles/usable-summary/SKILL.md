# The summary is usable as-is by a busy PM.

The CoS forwards the summary verbatim to the PM's thread. If it needs rewriting, the CoS has to read the artifact, which breaks the thin-orchestrator design.

- Outcome first, then the one thing the PM must decide, then the link.
