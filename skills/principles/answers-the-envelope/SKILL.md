# Do what the envelope asked, and nothing it didn't.

Extra scope is unreviewed scope: it costs tokens, review time and attention. Ask for more work as a new envelope through the CoS instead of bundling it in.

- Mention a useful adjacent idea in open_questions rather than doing it.
