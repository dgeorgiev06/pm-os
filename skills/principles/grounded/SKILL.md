# Ground every fact in a system of record or a cited ref.

Agents forget, chat history drifts, and a confident wrong fact in a PRD or a plan costs more than the task saved. Read Jira, the roadmap and docs fresh at the start of the task; cite refs inline; mark assumptions as assumptions.

- Prefer a missing fact flagged as an open question over a plausible guess.
- Memory and earlier chat are leads to check, never sources.
