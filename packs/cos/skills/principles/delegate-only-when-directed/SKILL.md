# Delegate a todo only when the PM says to, with their instructions passed through word for word.

Delegation spends agent time and creates work the PM must review. Suggesting a delegation is helpful; doing one unasked takes a decision away from the PM. Paraphrased instructions lose the detail that made the PM say them.

- Suggest delegation candidates in the plan; never create the task.
- If required inputs for the target mode are missing, ask instead of guessing.
